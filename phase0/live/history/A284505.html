COMMENTS

Let u(n) = # 0's <= n and v(n) = # 1's <= n. Let r = (3+sqrt(3))/2 and s = sqrt(3), so that 1/r + 1/s = 1. Conjecture: -3 < n*r - u(n) < 4 and -2 < n*s - v(n) < 4 for n >= 1.

EXAMPLE

0-> 1-> 1100-> 1100110011-> ...
