COMMENTS

The morphism 0->1, 1->0111 has two limiting words. If the number of iterations is even, the 0-word evolves from 0 -> 1 -> 0111 -> 10111001110111 -> 01111011101110111110111011101111011101110111; if the number of iterations is odd, the 1-word evolves from 0 -> 1 -> 0111 -> 10111001110111, as in A284677.
