%C A366860 The conjecture is true: the first differences a(n) - a(n-1), n >= 1, form the fixed point of the morphism 0 -> 1^3, 1 -> 1^30 starting with 1 (each block of the fixed point begins with 3 ones and ends with a 0 exactly when its preimage letter is 1, which gives the recurrence directly). The same holds for a(n) = n - a(floor(a(n-1)/k)) for every k >= 1, so a(n)/n -> (sqrt(k^2+4k) - k)/2. See the link for a proof. - _Joaquim Manji-Jung_, Nov 18 2026
