%C A226898 Greathouse's conjecture is true. If an odd prime q divides n, split the divisors into the chains d, d*q, ..., d*q^v (v the q-adic valuation of n); each chain has at least 2 elements, and an interval [u, e*u] contains at most one element of each chain since q >= 3 > e, so a(n) <= d(n)/2. If n = 2^v, then a(n) <= 2 <= (v+1)/2 for v >= 3. - _Joaquim Manji-Jung_, Nov 19 2026
