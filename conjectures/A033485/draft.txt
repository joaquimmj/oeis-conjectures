%C A033485 The conjectured value c = 1.64... is wrong: the limit exists and equals 2*log(2) = 1.3862... Writing beta(n) = n*a(floor(n/2))/a(n), one has a(2N) = 2*S(N) - a(N) + 1 with S(N) = a(1)+...+a(N), and S(N)/a(N) = Sum_k Prod_{j>k} (1 - beta(j)/j); if |beta(j) - log_2(j)| <= D on (N/2, N] this gives |beta(n) - log_2(n)| <= D + O(log log N/log N) for n = 2N, 2N+1, and a dyadic induction (base computed up to 2^29) yields beta(n) = log_2(n) + O((log log n)^2), hence a(2n)/a(n)*log(n)/n = 2*log(n)/beta(2n) -> 2*log(2). The ratio is 1.566 at n = 1.5*10^8 and still decreasing. - _Joaquim Manji-Jung_, Nov 19 2026
