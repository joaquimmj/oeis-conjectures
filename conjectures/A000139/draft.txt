%C A000139 Bala's conjecture is true. By Legendre's formula, v_2(a(n)) = s(n) + s(n+1) - s(3n) = c + 1 - t, where s = A000120, t is the number of trailing 1's of n and c is the number of carries in the binary addition n + 2n. If t >= 2 then c >= t; so a(n) is odd iff t = 1 and c = 0, i.e., iff n == 1 (mod 4) and n has no two adjacent 1's in binary, i.e., n is in A022341. - _Joaquim Manji-Jung_, Nov 18 2026
