# A295070 : a(n) = a(n−2) + b(n−1) + b(n−2), avec a(0) = 1, a(1) = 2 et b(0) = 3. Conjecture : a(n)/a(n−1) → 1. **Vraie.**

Les notations et le lemme 1 sont ceux de `proof.md` (si a(m) ≥ 2m + 2, alors b(m) ≤ 2m + 1).

1. Comme b(k) ≥ k + 1, on a a(n) − a(n−2) ≥ n + (n − 1) = 2n − 1. En sommant sur les indices de même parité,
   a(n) ≥ n²/2 − O(n). En particulier, a(m) ≥ 2m + 2 pour m ≥ 3 (vérifié directement pour les petits m), donc
   b(m) ≤ 2m + 1 par le lemme 1.
2. Comme a est croissante, 0 < a(n) − a(n−1) ≤ a(n) − a(n−2) = b(n−1) + b(n−2) ≤ 4n.
3. Donc 1 < a(n)/a(n−1) ≤ 1 + 4n/a(n−1) = 1 + O(1/n) → 1. ∎

Contrôle : `A295070_check.py` calcule 3000 termes avec le solveur de `compute.py`. Il vérifie les données OEIS,
a(n) ≥ 2n + 2 pour n ≥ 3, b(m) ≤ 2m + 1 et a(n) − a(n−1) ≤ 4n. Le calcul donne aussi a(n)/n² ≈ 0,516 en
n = 2999, ce qui est cohérent avec a(n) ~ n²/2.
