%C A123722 Both conjectures are true. s = A000224 is multiplicative with s(p) = (p+1)/2 and, for odd r, s(r) <= (r+1)/2 with equality iff r = 1 or r is prime. If n = 3r with 3 not dividing r, s(n) = ceiling((n+1)/3) becomes 2*s(r) = r+1, forcing r to be an odd prime; if 9 divides n, ratio bounds leave only n = 9. Conversely s(3p) = p+1 for every odd prime p. - _Joaquim Manji-Jung_, Nov 19 2026
%C A123723 The conjecture is true: writing n = 2^b*r with r odd, s(n) = ceiling((n+1)/4) becomes s(2^b)*s(r) = 2^(b-2)*r + 1; for b = 2 this forces s(r) = (r+1)/2, i.e., r prime; b = 3 gives only n = 8; and for b >= 4, s(2^b)/2^b <= 1/4 leaves no solution. - _Joaquim Manji-Jung_, Nov 19 2026
