%C A004123 Bala's conjectures are true, in the following form: if a(n) has e.g.f. G(exp(x)-1) with G an integral power series, then a(n) = Sum_j g_j*j!*Stirling2(n,j), and since k divides j! for j >= k, a(n) == Sum_{i<k} c_i*i^n (mod k) for some integers c_i. Hence a(n) mod k is periodic for n >= log_2(k), with period dividing the Carmichael function A002322(k), which divides phi(k). - _Joaquim Manji-Jung_, Nov 18 2026
%C A006531 The conjecture is true: Sum_k (-1)^k*Catalan(k)*k!*Stirling2(n,k) == Sum_{i<m} c_i*i^n (mod m), since m divides k! for k >= m, so a(n) mod m is periodic for n >= log_2(m) with period dividing A002322(m), which divides phi(m) (the factor (-1)^n has period 2). See A004123. - _Joaquim Manji-Jung_, Nov 18 2026
