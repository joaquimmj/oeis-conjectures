# oeis-walnut

Preuves (ou réfutations) de conjectures de l'OEIS sur des mots morphiques, avec le prouveur Walnut
(H. Mousavi ; J. Shallit, *The Logical Approach to Automatic Sequences*, 2022) et des arguments à la main.

- `REPORT.md` : résultats et niveau de certitude de chacun.
- `LOG.md` : journal.
- `phase0/` : état de chaque cible ; `python/` : générations indépendantes et tests ;
  `walnut/` : scripts, automates, sorties ; `notes/` : preuves à la main ; `drafts/` : brouillons OEIS (rien de soumis).

Travail préparé avec l'aide d'une IA (Claude) ; conjectures de R. J. Mathar et C. Kimberling.
