# oeis-walnut

Proofs and one disproof of conjectures in the OEIS on binary morphic words, conjectures by Clark Kimberling and
R. J. Mathar. The tools are the Walnut theorem prover, hand proofs and exact computation.

**Paper:** [Proofs and disproofs of 331 conjectures in the OEIS](paper/draft.pdf) (November 19, 2026; preprint, not refereed yet). Part I is the original note on binary morphic words; the other parts cover the branch `conjectures`. The tables are generated by `paper/make_tables.py`.

## Main result

Kimberling's 2017 conjecture in [A284364](https://oeis.org/A284364), also stated in
[A284365](https://oeis.org/A284365) and [A284366](https://oeis.org/A284366), is **false**. The smallest
counterexample is **n = 2,977,771**. You can check it without any theory: generate the fixed point of
0 → 1, 1 → 101010 and compare two integers (`python/independent_check.py`). It was submitted to the OEIS on
15 November 2026 and is under review.

## What is Walnut?

[Walnut](https://github.com/firetto/Walnut) is an automatic theorem prover for sequences generated by automata,
created by Hamoon Mousavi and developed by Jeffrey Shallit and others. You state a property in first-order logic,
such as "for every n, a(n) = b(n + 1)", and Walnut decides whether it is true for all n and answers TRUE or FALSE.
It gives a proof that covers infinitely many terms, not just a check on the first million. Here it proves the
equalities of Mathar and part of the bounds of Kimberling, which is why the repository is named after it.

## Results

| Entries | Result | Proof |
|---|---|---|
| A284364, A284365, A284366 | Kimberling's bound is **false**; first counterexample n = 2,977,771 | exact computation and integer check (`python/exact_A284364.py`, `python/independent_check.py`) |
| A283963, A283966, A284386, A284368, A284369, A284505, A045671, A045672 | Kimberling's bounds are true; exact inf and sup, never attained | exact computation (`python/discrepancy_exact.py`, `python/attainment.py`) |
| A284386, A284368 | the four bounds are also proved with Walnut plus a short hand argument | `python/make_sqrt13.py`, `notes/groupB_walnut_sqrt13.md` |
| A284948 | Mathar's equality is true | Walnut (`walnut/groupA_uniform.txt`) |
| A285358, A285076 | Mathar's equalities are true | by hand (`notes/groupA_handproofs.md`) and Walnut (`python/make_nonuniform.py`) |
| A284677 | the stated formula fails at n = 6; the corrected form is true | by hand and Walnut |
| A285383 | already proved by A. Ashburn (arXiv:2610.04842) | nothing claimed |

Kimberling's bounds are read with a(n) = position of the n-th 0 (or 1); written literally with a counting
function, they are false. In A284386 the constant r must be (5 + √13)/2.

## Layout

- `paper/`: the paper (`draft.tex`, `draft.pdf`).
- `python/`: independent generation of the sequences, checks and exact computation.
- `walnut/`: automata, Walnut scripts and raw outputs.
- `notes/`: hand proofs and the method of the exact computation.
- `results/`: tables and outputs of the computations.
- `drafts/`: one draft OEIS comment per entry.
- `phase0/`: copies of the OEIS entries and b-files used.
- `REPORT.md` (detailed results and how certain each one is) and `LOG.md` (work log) are in French.

## Reproduce

Python 3.9+ with `numpy`, Java 17+ for Walnut, and LaTeX (for example `tectonic`) for the paper.

```bash
python3 python/independent_check.py  # the counterexample, from the OEIS definitions only
python3 python/check_phase0.py        # definitions against the OEIS data
python3 python/check_live.py          # entries and b-files (copies in phase0/live)
python3 python/check_handproofs.py    # identities used in the hand proofs
python3 python/discrepancy_exact.py   # exact bounds (~45 s)
python3 python/discrepancy_bracket.py # cross-check with a second algorithm
python3 python/attainment.py          # whether the bounds are attained
python3 python/exact_A284364.py       # the counterexample in exact integers
python3 python/scout_groupB.py        # floating-point scan of 2·10^8 letters (~3 GB of RAM)
```

For Walnut, clone https://github.com/firetto/Walnut into `../Walnut` (or set `WALNUT_DIR`) and compile it.
`python3 python/make_uniform.py` writes the automata, and `walnut/groupA_uniform.txt` is fed to Walnut on standard
input. `python3 python/make_nonuniform.py` (needs `pip install licofage`, which requires numpy < 2) redoes the three
non-uniform proofs in about 3 minutes, and `python3 python/make_sqrt13.py` the √13 cases in about 30 seconds.
