A284364, section COMMENTS :

Let a(n) be the position of the n-th 0 and b(n) the position of the n-th 1. The conjecture above must be read as -2 < n*r - a(n) < 2 and -1 < n*s - b(n) < 2 (as literally written, with u(n) the number of 0's <= n, the quantity n*r - u(n) is unbounded). With this reading the conjecture is false. The upper bound 2 fails in both cases: the smallest counterexamples are n = 8933313 (the n-th 0 is at position 20222898) and n = 2977771 (the n-th 1 is at position 5334043), where the value is 2.00487... The exact extreme values are: inf(n*r - a(n)) = (-12-2*sqrt(21))/15, sup(n*r - a(n)) = (6+sqrt(21))/5, inf(n*s - b(n)) = (-9+sqrt(21))/5, sup(n*s - b(n)) = (6+sqrt(21))/5, with r = (9+sqrt(21))/6, s = (-1+sqrt(21))/2. Proof: Dumont-Thomas numeration for the morphism 0->1, 1->101010 expresses these quantities as sums of g_i*c^i over the digits, c being the conjugate eigenvalue; the extreme values solve a finite max/min system that is a contraction. - _Joaquim Manji-Jung_, Nov xx 2026
