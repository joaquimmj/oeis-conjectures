A284369, section COMMENTS :

Let a(n) be the position of the n-th 0 and b(n) the position of the n-th 1. The conjecture above must be read as -3 < n*r - a(n) < 4 and -2 < n*s - b(n) < 3 (as literally written, with u(n) the number of 0's <= n, the quantity n*r - u(n) is unbounded). With this reading the conjecture is true. The bound -2 for the 1's is the exact infimum; it is not attained since n*sqrt(3) is irrational. The exact extreme values are: inf(n*r - a(n)) = (-3-sqrt(3))/2, sup(n*r - a(n)) = 2+sqrt(3), inf(n*s - b(n)) = -2, sup(n*s - b(n)) = 1+sqrt(3), with r = (3+sqrt(3))/2, s = sqrt(3). Proof: Dumont-Thomas numeration for the morphism 0->1, 1->1001 expresses these quantities as sums of g_i*c^i over the digits, c being the conjugate eigenvalue; the extreme values solve a finite max/min system that is a contraction. - _Joaquim Manji-Jung_, Nov xx 2026
