A284368, section COMMENTS :

Let a(n) be the position of the n-th 0 and b(n) the position of the n-th 1. The conjecture above must be read as 1 < n*r - a(n) < 3 and -1 < n*s - b(n) < 1 (as literally written, with u(n) the number of 0's <= n, the quantity n*r - u(n) is unbounded). With this reading the conjecture is true. The exact extreme values are: inf(n*r - a(n)) = (1+sqrt(13))/3, sup(n*r - a(n)) = (4+sqrt(13))/3, inf(n*s - b(n)) = (-5+sqrt(13))/3, sup(n*s - b(n)) = (-2+sqrt(13))/3, with r = (5+sqrt(13))/2, s = (-1+sqrt(13))/2. Proof: Dumont-Thomas numeration for the morphism 0->1, 1->1011 expresses these quantities as sums of g_i*c^i over the digits, c being the conjugate eigenvalue; the extreme values solve a finite max/min system that is a contraction. - _Joaquim Manji-Jung_, Nov xx 2026
