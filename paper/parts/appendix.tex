\subsection{Python checks}
All $74$ check scripts of \texttt{python/} and \texttt{conjectures/} were run. $73$ exit normally and print the
expected confirmations, six of them after being re-run from the folder they read their data from, or with their
size argument; the remaining one, \texttt{A288997/dfao.py}, is a helper for an open case that needs an automaton
file as argument (for example: ``OK pour $n<4000$'' for \oeis{A000139}, the
counterexamples $n=8\,933\,313$ and $n=2\,977\,771$ in exact integers for \oeis{A284364}, ``n = 1..300 : OK'' for the
Sturm count of \oeis{A347171}, $a(5000)/a(4999)=-1.405177106052044\ldots$ for \oeis{A225132}, ``0 échec'' for the
$90$ complementary equations, ``ALL B-FILES OK'' for the b-files of Part~\ref{part:one}). Scripts that read their
data with a path relative to \texttt{conjectures/} were run from that folder. Not run: the crawler, the
generators called by other scripts, and \texttt{A022558/tilescope.py} (an open case).

The four entries added to the branch on the same day (commit \texttt{7194295}) were checked in the same way:
\texttt{A022344/check.py} ($4\,563$ pairs, no failure), \texttt{A083207/check.py} (maximal gap $12$ below
$10^5$), \texttt{A155200/check.py} ($n\le300$), and for \oeis{A033485} the base values were recomputed from
\texttt{beta.c} ($E_{27}=4.106847$, $E_{28}=4.161768$, equal to the values used) and \texttt{bootstrap.py 10001}
reproduces the recorded iteration. The Sturm count of \oeis{A347171} was re-run up to $n=300$: OK.

\subsection{Independent re-checks of the falsity claims}
On the same day, the data and the conjectures of every entry declared false in Part~\ref{part:two} and
Sections~\ref{s:A074355}, \ref{s:beatty} and~\ref{s:A299405} were fetched from the OEIS, and the counterexamples
were recomputed by a separate short program (not from the repository) from the printed data and constants: all
agree. The anti-tetranacci system was regenerated from its definition by a third program, which gives
$c(26)=113$ and the same $3\,333$ failures below $2\cdot10^5$.
